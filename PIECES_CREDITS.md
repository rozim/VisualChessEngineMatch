# Chess piece artwork

The chess piece images (`wK`, `wQ`, `wR`, `wB`, `wN`, `wP`, `bK`, `bQ`, `bR`,
`bB`, `bN`, `bP`) are the **Cburnett** chess set by Wikimedia Commons user
*Cburnett*.

- Source: https://commons.wikimedia.org/wiki/Category:SVG_chess_pieces
- Original files: `Chess_{p}{l|d}t45.svg` (e.g. `Chess_klt45.svg`).
- Author: Colin M.L. Burnett (Cburnett).

Only the filenames were changed (to `wK.svg` … `bP.svg`) to match the asset
catalog imageset names. The SVG content is unmodified.
